# Global Business Suite (GBS) — Release Notes Phase 18

**Release Version:** v18.0.0  
**Release Date:** August 7, 2026  

## Key Highlights

- **Plugin & Extension Marketplace**: Enterprise plugin store with micro-sandbox security isolation, version control, dependency validation, paid/free/private licensing, and user ratings/reviews.
- **Public SDK Platform & Developer Portal**: Native SDK distributions for JS/TS, Python, React Native, Flutter, Go, Java, .NET, and PHP alongside self-service OAuth app registration, API keys, and webhook management.
- **Low-Code / No-Code Visual Studio**: Visual Form Builder, Visual Workflow Builder, Visual Page Builder, Visual Dashboard Builder, and Business Rule Builder.
- **App & AI Marketplaces**: Marketplace catalog for enterprise business apps, prompt packs, autonomous AI agents, and workflow templates.
- **Unified Enterprise AI Copilot & Voice AI**: Multi-role Copilot for Admin, Partner, Customer, Developer, Marketing, CRM, Finance, Analytics, GBP, and Social Media with STT/TTS voice command processing.
- **Autonomous AI Agents & Document Intelligence**: Configurable autonomous agents (Marketing, SEO, Review, Sales, Finance, Security) and OCR invoice/contract processing.
- **Unified Enterprise Search**: Platform-wide semantic search across platform records, documents, CRM, GBP, social feeds, reports, and audit logs.
- **Expanded Integration Hub**: Connectors for M365, Google Workspace, Slack, Teams, Salesforce, HubSpot, QuickBooks, SAP, Stripe, and Power BI.
- **Future Readiness**: IoT sensor telemetry stream, Digital Twin operational scenario forecasting, and Hyperledger blockchain immutable audit ledger.
