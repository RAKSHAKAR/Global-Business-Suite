# Skill 04 — UI/UX Skill (GBS-AIOS)

## Purpose
Ensures world-class, premium enterprise UI aesthetics, seamless user flows, responsive layouts, micro-animations, and WCAG AA accessibility across all GBS web portals and mobile screens.

## Responsibilities
• Enforce Fortune 100 enterprise UI standards: dark/light theme harmony, dynamic elevation, glassmorphism accents.
• Eliminate generic placeholders; require real-time interactive previews and state visualizations.
• Ensure full accessibility: keyboard focus rings, screen-reader aria labels, min 4.5:1 contrast ratios.
• Maintain responsive breakpoint consistency (Mobile: <640px, Tablet: 640-1024px, Desktop: >1024px).
