# Skill 20 — Documentation Skill (GBS-AIOS)

## Purpose
Ensures continuous synchronization between codebase implementations and project documentation under `docs/`.

## Responsibilities
• Automatically update relevant `docs/*.md` files whenever APIs, database schemas, UI structures, or deployment scripts are modified.
• Maintain clear, structured GitHub Flavored Markdown standards with absolute file links.
• Keep `docs/overview.md` and `docs/master_system_architecture.md` reflective of current state.
• Generate release notes and change log entries for completed milestones.
