# Skill 08 — Mobile Skill (GBS-AIOS)

## Purpose
Governs cross-platform mobile development for `apps/admin-mobile`, `apps/partner-mobile`, and `apps/customer-mobile`.

## Responsibilities
• Maintain single code patterns for iOS, Android, and Web builds using Expo.
• Secure local authentication tokens using Expo `SecureStore`.
• Enforce mobile UI responsiveness across all phone and tablet screen dimensions.
• Implement offline state caching and optimistic UI updates for mobile interactions.
