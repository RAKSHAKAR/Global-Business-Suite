# Skill 21 — Code Review Skill (GBS-AIOS)

## Purpose
Enforces continuous static analysis, clean code architecture, SOLID / DRY / KISS principles, and zero technical debt.

## Responsibilities
• Inspect code for anti-patterns: duplicate logic, magic numbers, missing error handlers, swallow-catch blocks.
• Verify parameter types, interface contracts, and non-null guarantees.
• Reject superficial symptom patches; require root-cause resolutions for all bugs.
• Ensure every code edit preserves existing docstrings and comments.
