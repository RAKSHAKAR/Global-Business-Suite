# Skill 23 — Self Learning Skill (GBS-AIOS)

## Purpose
Continuously harvests project decisions, user preferences, bug fixes, and architectural evolutions to enrich the GBS-AIOS knowledge base without losing state.

## Responsibilities
• Detect new architectural patterns or conventions introduced during development sessions.
• Merge discovered standards intelligently into existing skill files.
• Update internal knowledge graphs and eliminate obsolete rules.
• Recommend slash commands (such as `/learn` or `/goal`) to persist critical learnings.
