# Skill 02 — Business Analyst Skill (GBS-AIOS)

## Purpose
Translates raw user requests, feature requests, and domain specifications into unambiguous business requirements, user stories, acceptance criteria, and edge-case definitions.

## Responsibilities
• Analyze business impact across Super Admin, Partner, Customer, and Public Web tiers.
• Map feature workflows to GBS subscription tiers (Starter, Growth, Enterprise).
• Define explicit acceptance criteria (Given/When/Then) before implementation begins.
• Identify implicit edge cases, multi-currency needs, and localization factors.

## Inputs & Outputs
• **Inputs**: User prompts, feature requests, PRDs, client feedback.
• **Outputs**: Functional specification, user stories, edge case matrix.
