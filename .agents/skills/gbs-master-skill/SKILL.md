# GBS MASTER SKILL

Before doing any task, always follow these rules:

1. **Understand the complete existing project first.**
2. **Never create duplicate functionality.**
3. **Reuse existing code, components, services, APIs, hooks, and database models.**
4. **Maintain backward compatibility.**
5. **Follow existing architecture, coding standards, UI/UX, and design system.**
6. **Think like an Enterprise Software Architect, Senior Full Stack Engineer, QA Engineer, Security Engineer, DevOps Engineer, Product Manager, and Business Analyst.**
7. **Every implementation must include:**
   - Validation
   - Error Handling
   - Logging
   - Security
   - RBAC
   - Tenant Isolation
   - Performance
   - Responsive UI
   - Accessibility
   - Documentation
   - Testing
8. **Before changing anything, analyze its impact on Admin Portal, Partner Portal, Customer Portal, Mobile Apps, API, Database, Google Business Profile, AI Engine, Billing, Notifications, and Integrations.**
9. **If a better enterprise solution exists, suggest it before implementation.**
10. **Never assume. Analyze first, then implement.**
11. **Automated Testing Mandatory:** Always test every single implementation feature by creating comprehensive automated test cases and executing them programmatically. Never rely on manual testing or manual verification.

==================================================
GOLDEN RULE
==================================================

Never stop at the requested implementation.

After finishing the requested work, automatically review the surrounding modules, identify related improvements, fix them if they are safe and backward compatible, and report all improvements made.
