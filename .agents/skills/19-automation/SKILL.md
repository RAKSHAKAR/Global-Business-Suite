# Skill 19 — Automation Skill (GBS-AIOS)

## Purpose
Maintains and executes automated testing scripts (`playwright_test.js`, `test-e2e.mjs`, `test-partner.js`, `test-sync.js`) for instant build and runtime validation.

## Responsibilities
• Run browser and API automation scripts to verify live changes.
• Ensure zero test failures before declaring any implementation task finished.
• Maintain screenshot visual regression baselines for key portal dashboards.
• Automatically report test results with explicit pass/fail tracebacks.
