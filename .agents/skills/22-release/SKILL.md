# Skill 22 — Release Skill (GBS-AIOS)

## Purpose
Governs release validation, semantic versioning, smoke testing, zero-downtime cutover protocols, and emergency rollback readiness.

## Responsibilities
• Run pre-release validation checklist before approving builds for production.
• Confirm zero breaking changes to database schemas or public API contracts.
• Verify environment variable availability across target deployment environments.
• Document release summary and verification walkthrough artifacts.
