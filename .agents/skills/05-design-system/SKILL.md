# Skill 05 — Design System Skill (GBS-AIOS)

## Purpose
Maintains single-source-of-truth for GBS visual tokens, CSS variables, shared UI primitives, and design system documentation.

## Responsibilities
• Enforce tokens from `packages/gbs-design-system.css` and `docs/GBS_DESIGN_SYSTEM_MASTER_GUIDE.md`.
• Prevent ad-hoc CSS or inline style duplication.
• Maintain standard component specs for `Button`, `Input`, `Modal`, `Table`, `Badge`, `Card`, `Sidebar`, `Header`, `Captcha`.
• Support partner white-label CSS overrides via tenant CSS variable injection.
